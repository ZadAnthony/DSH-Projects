# Native component reuse

Targets DeepSeek Harness 0.2.2-rc.3 (38a6a5c965aa99ab525161efb7cc5cf1fe62fced), MIT. Limited Agent driver, inbox, tool batch scheduling, model adapters and private UI algorithms retain their actual source commits and license records under lib/notices, including the original 0.2.0-rc.2 source at 639ed015397290b3745d163aafe02ffee4aa3f84 and explicitly recorded later adaptations. The relative provider-sdk directory is an ordinary SDK copy with its own source record, not a replacement package for DSH or a same-name SDK override. The host and its native components are ordinary peers; this package contains no replacement DSH distribution. Tool execution uses the public ToolExecutionPipeline and scoped native/PTC executors. Finite upstream PTC transport sources are bundled with their source commit and hashes under lib/notices/native-host-sources.
